## 1. プロダクト概要

tomu は、ユーザーのローカルマシン上で動作する**自律型デスクトップ AI エージェント**アプリケーションである。
単なるチャットボットではなく、ファイル操作・ターミナル実行・ブラウザ操作・記憶の永続化を行い、ユーザーの「もう一人の自分」として自律的に思考・行動する。

### 1.1 プロダクトビジョン
- AI を「道具」ではなく「パートナー」として位置づける
- ローカルファースト: すべてのデータはユーザーのマシン上に保存
- 拡張可能: Markdown (Skills) による誰でもできる機能拡張 + Plugin (JS) による開発者向け深い拡張

### 1.2 ターゲットユーザー
- ソフトウェアエンジニア（コーディング支援、コードレビュー）
- パワーユーザー（ファイル管理、自動化タスク）
- クリエイター（コンテンツ作成、リサーチ）

## 2. 機能要件

### 2.1 コアエージェント機能 (P0 - Must Have)

| ID | 機能 | 説明 |
|:---|:-----|:-----|
| F-001 | **LLM プロキシ** | ローカル API サーバー経由で複数 AI プロバイダー (OpenAI, Anthropic, Gemini, Ollama 等) と通信 |
| F-002 | **エージェントループ** | LLM の tool_calls をインターセプトし、ツール実行→結果を LLM に再送信する自律的思考ループ |
| F-003 | **ターミナル実行 (Bash)** | node-pty を用いた永続的疑似ターミナルでのコマンド実行 |
| F-004 | **ファイル操作** | ローカルファイルの読み取り (Read)、書き込み (Write)、編集 (Edit)、検索 (Glob/Grep) |
| F-005 | **コンテキスト合成** | SOUL.md + USER.md + RAG + Skills を動的に組み合わせたシステムプロンプト生成 |
| F-006 | **チャット UI** | ストリーミング (SSE) 対応のリアルタイムチャットインターフェース |
| F-007 | **スレッド管理** | 会話の作成・保存・検索・再開・削除 |

### 2.2 記憶・コンテキスト管理 (P0)

| ID | 機能 | 説明 |
|:---|:-----|:-----|
| F-010 | **Dual Memory Architecture** | 確実な事実 (Markdown Profile) と曖昧な会話履歴 (Vector DB) の二層構造 |
| F-011 | **Semantic RAG** | sqlite-vec による 1536 次元ベクトル検索で過去の関連会話を自動抽出 |
| F-012 | **People Profiles** | チャット相手の個人情報を Markdown/YAML で永続化 (ハルシネーション防止) |
| F-013 | **Daily Notes** | 日付別メモリファイル (YYYY-MM-DD.md) + MEMORY.md の自動読み込み |
| F-014 | **自動記憶抽出** | Hidden Prompt による会話からの重要情報自動抽出・Vector DB 保存 |
| F-015 | **記憶クリーンアップ** | 不要になった一時記憶の自動判定・削除 |

## 3. 非機能要件

### 3.1 セキュリティ
- API キーはローカルサーバー内に隠蔽し、UI/CLI に露出しない
- ツール実行結果に含まれるシークレットはサニタイズして LLM コンテキストに渡す
- Widget は sandbox 付き iframe で実行し、Node.js API やファイルシステムへのアクセスを遮断
- プロンプトレベルでもシークレット漏洩防止ルールを適用

### 3.2 パフォーマンス
- ストリーミング (SSE) による低レイテンシ応答表示
- sqlite-vec によるローカルベクトル検索 (外部 API 不要)
- サブエージェントの非同期バックグラウンド実行によるメインスレッド非ブロック

### 3.3 信頼性
- node-pty プロセスのタイムアウト制御 (SIGINT による強制停止)
- サブエージェントのライフサイクル管理 (started → running → completed/failed)
- Triple Storage (SQLite + JSON + Markdown) によるデータ冗長性

### 3.4 拡張性
- Skills: Markdown 追加だけで機能拡張 (コード不要)
- Plugins: JS モジュールによるシステムレベル拡張
- MCP: 外部サーバーとの標準プロトコル接続
- サブエージェント: ソースコードレベルで新種追加可能

### 3.5 デプロイ
- デスクトップアプリとして配布 (Electron)
- 完全ローカル動作 (localhost:23001 のループバック通信のみ)
- マルチテナント非対応 (シングルユーザー前提)

---

## 4. 制約事項

1. パブリックインターネットへの API 公開は行わない (localhost only)
2. マルチテナント/クラウドデータベースは対象外
3. UI レンダリングはクライアント側の責務 (サーバーはデータとロジックのみ提供)
4. サブエージェント定義は現時点ではハードコード (将来的に設定ファイル化を検討)
