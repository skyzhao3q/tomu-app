# Project Relationships: Alma and Protan

このドキュメントでは、現在稼働しているオリジナルアプリケーション「Alma」と、本リバースエンジニアリングを通じてこれから作成する新規プロジェクト「Protan」の関係性を整理します。

## 1. Alma (アルマ)
- **正体**: 現在稼働している「オリジナル」の自律型AIエージェント・アプリケーション。
- **出所**: `.dmg` ファイルや Bundle ID (\`com.yetone.alma\`) から解析。
- **特徴**: Electron + Bun ベース。単なるチャットUIにとどまらず、\`node-pty\` によるバックグラウンドターミナル操作や、\`Fatigue\`（疲労度）システム、\`Skills\`（動的プロンプト注入による無制限の拡張）を備え、Macに常駐する「人格を持ったエージェント」として設計されています。

## 2. Protan (プロタン)
- **正体**: **Almaのリバースエンジニアリング結果を基にして、これからあなたが開発する「分身（クローン）」プロジェクトの名前**です。
- **現状**: 現在のPC上に「プロタン」のソースコードはまだ存在していません。
- **目的**: Almaの優れたアーキテクチャ（Local API Hub, Skills, pty連携など）を抽出し、この \`alma-prj/\` フォルダに蓄積された設計書をベースに、一から「プロタン」を構築することが今回の目的です。

---

*※注: この設計図 (\`alma-prj/\`) に含まれるすべてのアーキテクチャ、API、パッケージ情報は、純粋に「Alma」のアプリバイナリ (\`app.asar\`) を解析・抽出した結果のみで構成されています。*
